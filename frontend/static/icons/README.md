# PWA App Icons

Place your PWA app icons here:

- `icon-192.png` — 192×192px PNG (required by Android Chrome for PWA install prompt)
- `icon-512.png` — 512×512px PNG (required for splash screen and app listing)

Both icons should use the Swipetern brand palette:
- Background: `#020617` (Slate 950)
- Accent: `#d946ef` (Fuchsia)

You can generate these from any icon tool (e.g. [RealFaviconGenerator](https://realfavicongenerator.net/),
[PWABuilder](https://www.pwabuilder.com/imageGenerator)) using the Swipetern logotype.
